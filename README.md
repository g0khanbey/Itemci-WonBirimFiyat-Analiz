# Itemci Won Fiyat Analiz (Chrome Extension)

Itemci.com üzerindeki WON satış ilanlarını analiz ederek en düşük WON fiyatlarını hızlı ve otomatik şekilde tespit etmenizi sağlayan bir Chrome uzantısıdır.

## Özellikler

- Itemci.com sayfasındaki WON ilanlarını otomatik tarar  
- En düşük WON fiyatını anlık olarak gösterir  
- Tarayıcı içinden tek tıkla kullanım  
- Hafif ve hızlı yapı  
- Manifest V3 uyumlu  

## Nasıl Çalışır?

1. Itemci.com üzerinde WON satışlarının bulunduğu sayfayı açın  
2. Chrome araç çubuğundaki **Itemci Won Fiyat Analiz** uzantı ikonuna tıklayın  
3. Uzantı, sayfadaki ilanları analiz ederek en düşük WON fiyatını tespit eder  

![Itemci Won Fiyat Analiz](https://raw.githubusercontent.com/g0khanbey/Itemci-WonBirimFiyat-Analiz/main/Ekran%20Al%C4%B1nt%C4%B1s%C4%B1.PNG)

## Kurulum (Manuel)

1. Bu repoyu bilgisayarınıza indirin veya klonlayın  
2. Chrome’da `chrome://extensions` adresine gidin  
3. Sağ üstten **Geliştirici modu**nu aktif edin  
4. **Paketlenmemiş uzantı yükle** butonuna tıklayın  
5. Proje klasörünü seçin  

## Kullanılan Teknolojiler

- JavaScript  
- Chrome Extension API (Manifest V3)  
- DOM (HTML) analiz işlemleri  
- Popup arayüzü  

## İzinler

Uzantı yalnızca aşağıdaki izinleri kullanır:

- `activeTab` – aktif sekmedeki WON ilanlarını okumak için  
- `scripting` – sayfa üzerinde analiz yapmak için  

Herhangi bir kişisel veri toplanmaz veya saklanmaz.

## Sorumluluk Reddi

Bu uzantı resmi olarak Itemci.com ile bağlantılı değildir.  
Yalnızca herkese açık olan sayfa verileri analiz edilir.
